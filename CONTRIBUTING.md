# Contributing

Thank you for helping improve the Virelix Transparency Project. Contributions should be focused, respectful, and traceable to legitimate public information.

## Factual submissions

- Provide the original public source for each factual claim.
- Include the source title, publisher, URL, publication date, and source type when available.
- Explain what the source supports and distinguish direct evidence from interpretation.
- Use the verification and location precision classifications in [METHODOLOGY.md](METHODOLOGY.md).
- Do not fill gaps with estimates or copied unsourced coordinates.
- Flag corrections, stale records, and uncertainty clearly.

## Development

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```

Keep the map as the primary experience, prefer small reusable components, and keep static records in `data/`. Do not add authentication, paid APIs, unnecessary backend services, or real camera locations without a separate source review.

## Safety

This project does not support vandalism, destruction, interference with equipment, harassment, or unlawful activity. Do not submit confidential license-plate scans, individual vehicle histories, personal tracking information, unlawfully obtained information, or confidential law-enforcement data. The project does not accept features intended to facilitate evasion of law enforcement.
